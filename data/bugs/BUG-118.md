# BUG-118: Inbound Calls Drop When Agent Answers via Softphone on Firefox

## Summary
Agents running CallFlow CRM on Mozilla Firefox report inbound calls immediately disconnecting when clicking "Accept Call".

## Reported Environment
Production (Firefox v118+ on Windows/macOS)

## Root Cause
Firefox formats ICE trickle candidates with subtle SDP attribute ordering differences compared to Chromium. The CallFlow WebRTC gateway was throwing a JSON schema deserialization error when encountering the `candidate-attribute` flag without an explicit `ufrag`.

## Resolution
Updated the signaling parser to gracefully tolerate optional `ufrag` fields in ICE candidates and added Firefox headless integration testing in CI/CD.
