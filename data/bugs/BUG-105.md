# BUG-105: MFA Verification Code Accepted After Expiration Window

## Summary
TOTP multi-factor verification tickets remained accepted for up to 15 minutes instead of the specified 5-minute security TTL window.

## Reported Environment
Staging

## Root Cause
The MFA verification challenge TTL was read from the general session cache configuration (`SESSION_TTL=900`) instead of the specific `MFA_CHALLENGE_TTL=300`.

## Resolution
Corrected the configuration binding in `AuthChallengeService.java` to reference `MFA_CHALLENGE_TTL`. Added unit and integration tests verifying code rejection at minute 6.
