# BUG-131: Ticket Reassignment Fails with 500 Error When Agent Has Max Capacity

## Summary
When a supervisor manually reassigns a ticket to an agent who already has 5 active tickets, the backend crashes with `HTTP 500 Internal Server Error` instead of displaying a clear validation warning.

## Reported Environment
Production

## Root Cause
`TicketAssignmentService.reassign()` threw an uncaught `CapacityExceededException` that bypassed the HTTP exception mapper.

## Resolution
Added an explicit check for capacity returning `HTTP 409 Conflict` with a structured payload `{ "error": "AGENT_AT_CAPACITY", "current": 5, "max": 5 }`.
