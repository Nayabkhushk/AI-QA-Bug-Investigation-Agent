# BUG-162: CSV Export of Call Detail Records Times Out for Ranges Exceeding 30 Days

## Summary
Generating a CSV export for Call Detail Records (CDR) spanning more than 30 days results in an HTTP 504 Gateway Timeout on tenants with high call volumes.

## Reported Environment
Production

## Root Cause
The export was executed synchronously in the HTTP request thread. The underlying SQL query performed a sequential table scan on `call_records` lacking a composite index on `(tenant_id, created_at)`.

## Resolution
Added composite B-tree index `idx_call_records_tenant_created` and shifted export jobs to asynchronous worker queues via Celery with S3 presigned download links.
