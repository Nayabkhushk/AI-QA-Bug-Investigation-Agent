# BUG-177: Duplicate Webhook Delivery Causes Double Charge on Tenant Invoices

## Summary
When Stripe retried network timeouts on the `invoice.payment_succeeded` webhook, CallFlow CRM created duplicate receipt records and processed secondary renewal charges against the customer card.

## Reported Environment
Production

## Root Cause
The webhook consumer lacked an atomic database transaction lock around `billing_webhook_events`. The two concurrent webhook deliveries both saw zero rows for `event_id` and proceeded with processing.

## Resolution
Added a database UNIQUE constraint on `billing_webhook_events(stripe_event_id)` and wrapped ingestion in `INSERT ... ON CONFLICT DO NOTHING`.
