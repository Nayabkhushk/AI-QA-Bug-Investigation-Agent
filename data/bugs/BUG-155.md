# BUG-155: Real-Time Notification Bell Counter Shows Negative Values

## Summary
Rapidly clicking multiple "Mark as Read" buttons on incoming ticket alerts caused the top navigation unread badge to display negative integers (e.g., `-2`).

## Reported Environment
Staging & Production

## Root Cause
Client-side optimistic decrement executed without clamping to zero (`unreadCount - 1`). If the WebSocket update arrived concurrently, the counter decremented twice for the same event.

## Resolution
Clamped the badge count in the React UI state to `Math.max(0, count)`.
